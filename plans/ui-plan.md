## 4. 화면 구성

### 설정
1. **머리글**
   - 로고 마크와 "게이트 · PLANT"(이름은 임시, 7절)
   - 탭: 설정 / 감사 기록
   - 상태 표시 3개: 게이트 켜짐 · 판단 모델 연결됨 · NER 사용 안 함
2. **연결 상태** 카드 3개와 [다시 확인] 버튼
   - 게이트: 켜짐 여부, 마지막 요청 시각, 정책 파일을 반영한 시각
   - 판단 모델 Laya: 연결됨·사용 안 함·응답 없음, 주소(`127.0.0.1:8000`), 모델 이름(`JEV_MODEL`)
   - NER: 같은 세 상태, 주소(`127.0.0.1:8001`), 서버 응답 여부, [켜기] 버튼, "서버 띄우는 방법" 링크
3. **문장으로 정책 바꾸기**
   - 입력칸 → [해석하기] → "이렇게 이해했어요" 상자
   - 상자 내용: 바뀌기 전 → 후 배지, 효과 설명, 경고(예: NER을 쓰지 않음), [이대로 저장]·[다시 쓰기], 설정 키
   - 저장하지 않는 결과(unclear·path·unsupported·error)는 해석기 안내 문구를 그대로 보여 준다.
   - 느슨해지는 변경은 화면에서도 한 번 더 확인한다(`gate.policy.loosened`).
   - 예시 문장을 버튼으로 둔다.
4. **지금 정책**
   - 번호·비밀값 8줄: 처리 3택, 공개 범위(선택 상자 또는 자물쇠), "찾는 규칙 보기"(쉬운 설명·예·정규식 이름과 패턴·추가 확인, 고정값이면 이유)
   - 이름·주소 같은 정보(NER) 11줄: 처리 4택. plain 묶음은 "다섯 가지가 함께 바뀌어요"라고 적는다. NER을 쓰지 않으면 "지금은 적용되지 않아요"를 띄운다.
   - 사용자가 정한 값은 "내가 바꿈"으로 표시한다.
5. **내가 정한 문장:** 목록(문장, 결과, 시각, 맥락 규칙이면 "지금은 효과 없음"), [지우기], [마지막 변경 되돌리기]
6. **꼬리말:** "이 화면은 이 컴퓨터에서, 내가 연 터미널에서만 열려요. AI 에이전트는 정책을 바꿀 수 없어요."

### 감사 기록
- 결과별 건수: 허용·가림·물어봄·거부
- 거르기: 기간(오늘·최근 7일·전체), 결과, 파일 이름
- 표: 시각, 파일, 결과(물어봄이면 → 이번만 허용·거부함), 이유, 프로그램
- 꼬리말: 기록은 이 컴퓨터에만 있고, 내용은 지문(HMAC)으로만 남는다. `gate audit`으로도 볼 수 있다.
- 자료는 `gate.audit.read_records`로 읽는다. 필드는 `ts`, `process`, `op`, `path`, `decision`, `reason`, `findings`, `approval` 등이다(`gate/audit.py` docstring).

## 5. 보안 조건 (구현 때 지킬 것)

원칙: 정책은 사람만 바꾼다(`plans/implementation-plan.md` 2절 "정책 지정"). 에이전트가 이 화면을 써서 정책을 바꾸거나 기록을 지울 수 없어야 한다.

- `gate ui`는 사용자 터미널에서만 실행한다.
  - 127.0.0.1(IP 리터럴)에만 바인드한다.
  - 실행할 때마다 새 무작위 토큰을 만들고, 브라우저를 토큰이 든 주소로 연다.
  - 토큰은 파일에 남기지 않는다.
- 모든 요청을 이렇게 검사한다.
  - 토큰을 확인한다.
  - `Host` 헤더가 `127.0.0.1:<포트>`인지 확인한다(DNS rebinding 방지).
  - 바꾸는 요청은 POST만 받고 `Origin`을 확인한다(CSRF 방지).
- 게이트 소켓(에이전트용)에는 지금처럼 정책을 바꾸는 요청을 두지 않는다. UI 서버는 데몬과 별개 프로세스로, 사용자 권한으로 정책 파일을 쓴다.
- 정책 쓰기는 `gate/policy_cli.py`와 같은 동작을 따른다: 기록 쌓기(`_push_history`), 되돌리기, 완화 확인, 0600 쓰기.
  - 지금 함수는 터미널 질문(`_Prompt`)에 묶여 있다. 그래서 "바꿈 계산·검사"와 "묻기"를 나눠 화면과 CLI가 같이 쓰게 고친다.
- 에이전트 샌드박스에서 127.0.0.1 TCP로 UI 포트에 닿을 수 있는지 Phase 6 하네스에 시도를 더해 확인한다. 닿더라도 토큰 없이 막히는지 본다.
- 상태 확인(laya-serve·nerserve `/health`)은 127.0.0.1에만 한다.
- 화면의 정규식은 `gate.detectors`의 패턴에서 읽어 보여 준다. 따로 적은 문자열을 두지 않는다.

## 6. 구현 계획 (초안, 다음 세션에 확정)

1. **8-1 서버:** `gate ui`(표준 라이브러리 `http.server`). 토큰·Host·Origin 검사, 정적 화면 한 묶음(HTML·CSS·JS, 외부 의존 없음).
2. **8-2 API**
   - 읽기: `GET /api/state`(정책, 내가 정한 문장, 기본값, 정규식 정보), `GET /api/status`(데몬·Laya·NER), `GET /api/audit`(거르기)
   - 해석: `POST /api/interpret`(문장 → 해석 결과, 저장하지 않음)
   - 바꾸기: `POST /api/save`(해석 결과 저장, 완화면 확인 값 필요), `POST /api/set`(직접 고르기), `POST /api/remove`, `POST /api/undo`
3. **8-3 설정 화면, 8-4 감사 기록 화면:** 3·4절 기준으로 만든다.
4. **테스트**
   - 토큰·Host·Origin이 틀리면 거부되는지
   - 완화할 때 두 번 확인하는지
   - 화면으로 저장한 결과가 `gate policy`로 저장한 것과 같은지
   - 하네스 시도(에이전트가 UI 포트로 정책을 바꾸려는 시도)
5. 끝나면 브랜치 + PR로 올린다. 커밋과 PR 본문에 AI 흔적을 남기지 않는다.

## 7. 미결 (구현 전에 사용자에게 묻는다)

1. **제품 이름:** 머리글의 "게이트 · PLANT"는 임시다.
2. **로고 파일을 공개 저장소에 넣을지:** 넣지 않으면 실행할 때 로고 없이 이름만 보인다.
3. **글꼴**
   - 로컬 화면이 Google Fonts를 부르면 열 때마다 외부 요청이 나간다.
   - 추천: 글꼴 파일을 함께 넣거나(OFL 라이선스), 시스템 글꼴로 대체한다.
4. **NER [켜기] 버튼이 할 일**
   - 추천: 설정(`ner_backend: server`)만 바꾸고, NER 서버가 응답할 때만 누를 수 있게 한다. 서버 실행은 화면이 하지 않는다.
   - 응답하지 않는 서버를 켜면 모든 읽기가 막히기 때문이다.
5. **기관 정책 기능**(관리자가 정한 값은 사용자가 못 바꿈)은 이번 범위 밖이다. 필요하면 새 기능으로 따로 정한다.
